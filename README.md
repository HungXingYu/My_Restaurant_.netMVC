<h2 id="1"> 專案概述--Project Description</h2>

> 學習.net MVC 時練習用專案
>
> 功能目前依照練習分為：
>
> 1. 未將餐廳類別獨立成一個Table，使用Restaurant_old資料表
>     *  分頁瀏覽餐廳清單
>     *  以餐廳中、英文名進行模糊搜尋
>     *  顯示各餐廳詳細資料
>     *  新增一筆餐廳資料
> 2. 將餐廳、餐廳類別各獨立成一個Table後Join，使用ResaturantCategoryViewModel(一對一)
>     * 分頁瀏覽餐廳清單
> 3.  將餐廳、餐廳類別各獨立成一個Table後Join，使用Dapper
>     * 分頁瀏覽餐廳清單，可選擇排序依據
>     * 以餐廳中、英文名進行模糊搜尋，搜尋結果可選擇排序依據
>     * 顯示各餐廳詳細資料
>     * 新增一筆餐廳資料，新增餐廳頁面的餐廳類別下拉選單無需要類別時可自行新增餐廳類別
